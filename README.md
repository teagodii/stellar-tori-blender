# Stellar Tori for Blender

A Blender extension that generates the **Stellar Tori**: 45 mathematically placed tori (or planes) that combine into 63 configurations. It uses the same geometry truth as the interactive viewer at [stellartori.com](https://stellartori.com).

> **Status: early development.** The repository is set up but the extension is not installable yet. The first release covers base generation only: tori and planes with configurable dimensions and positions.

## Planned for the first release

- Pick a configuration from the same 3 × 3 Vt / Wt / Mt grid the web viewer uses.
- Generate tori or planes, one object per torus, at the canonical positions and rotations.
- Adjust major and minor radius, mesh segments, plane size and subdivisions, and the shell offset distances.

Wireframe styling, particles and glass render scenes come later.

## Requirements

Blender with extension support (4.2 or newer). Development and testing use Blender 5.1.
